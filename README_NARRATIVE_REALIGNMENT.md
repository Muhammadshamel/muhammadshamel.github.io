# Portfolio Narrative Realignment

This version realigns the site into a consulting-style story while preserving the existing repository structure, shared rendering, responsive design and hover interactions.

## Page flow

1. Hero — who Muhammad is
2. Executive Profile — how he approaches architecture
3. Architecture Capabilities — the disciplines he brings
4. What I Help Organizations Achieve — the business problems he solves
5. Architecture in Practice — bridge from promise to proof
6. Selected Enterprise Engagements — evidence and outcomes
7. Professional Journey — progression and credibility
8. Architecture Philosophy — how decisions are made
9. Contact — the conversations he is open to

## Synchronization

Production and the local editor both use `docs/css/site.css` and `docs/js/site.js`. The editor adds only its local editing controls. New outcome cards use the same upward hover movement and shadow as the existing impact and capability cards. Engagement rows retain their horizontal movement and chevron animation.
